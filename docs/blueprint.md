# **App Name**: BookLoop

## Core Features:

- Book Listing: Allow students to create listings for books they want to sell, with details like condition and grade level.
- Listing Management: Enable users to manage their active listings, including editing or removing them.
- Messaging System: Provide a platform for buyers and sellers to communicate about book listings and transactions.
- Sales Tracking: Keep a record of completed transactions for both buyers and sellers.

## Style Guidelines:

- Background color: Light cream (#003631) to provide a soft, neutral base.
- Primary color: Earthy green (#FFEDA8) to evoke a sense of nature and simplicity.
- Accent color: Muted gold (#062723) to highlight key elements without being too distracting.
- Body and headline font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth or personality.
- Use minimalist icons for navigation and actions to maintain a clean look.
- Maintain a clean and spacious layout with clear visual hierarchy to prevent the interface from feeling crowded.
